Исправление колеса MDK Shop — новая футболка остаётся видимой

Эта версия заменяет предыдущее исправление.

Колесо снова показывает пять последних футболок из каталога, включая новые
товары из бота. Если есть отдельный принт в art.js, используется он. Если его
нет, используется фото товара: оно вписано в сектор, не увеличивается при
выборе и ограничено SVG clipPath по границам сектора.

Фото не превращается автоматически в прозрачный принт. Чтобы показать
отдельный принт, добавьте его файл и путь по ID товара в window.PRINT_ART.

Установка:
1. Распакуйте архив в корень репозитория сайта с заменой файлов.
2. Опубликуйте app.js, art.js, styles.css и index.html на GitHub.
3. После обновления GitHub Pages перезагрузите страницу.

Версии CSS и JS в index.html повышены, чтобы браузер загрузил исправление.
products.js, фотографии и Telegram-бот в архив не входят и не заменяются.

Проверка (необязательно, нужен Node.js):
  node --test tests/wheel.test.cjs

Семь проверок, включая появление Doflamingo без отдельного принта, отбор пяти
последних футболок, сохранение готовых принтов и обрезку фото границами сектора.
