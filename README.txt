Исправление колеса принтов MDK Shop

Причина: app.js подставлял обычную фотографию товара, если для его ID не было
отдельного принта в art.js. Белый фон и сама футболка попадали в колесо.

Теперь колесо выбирает до пяти последних футболок, у которых есть отдельный
принт в window.PRINT_ART. Отбор идёт до ограничения количества: товары без
принтов не вытесняют готовые изображения. Фотографии товаров больше не
используются как запасной вариант. Сам товар остаётся в каталоге.

Установка:
1. Распакуйте архив в корень репозитория сайта MDK_shop с заменой файлов.
2. Опубликуйте app.js, art.js, styles.css и index.html в GitHub-репозитории сайта.
3. После обновления GitHub Pages перезагрузите страницу.

В index.html повышены версии изменённых JS/CSS, чтобы браузер запросил новые файлы.
products.js, изображения и файлы Telegram-бота в этот архив не входят.

Чтобы новая футболка появилась также в колесе:
подготовьте отдельное изображение принта с прозрачным фоном, загрузите его
в images/prints/ и добавьте соответствие ID товара и пути в window.PRINT_ART
в art.js. Например для ID 14:
  14: "images/prints/doflamingo-art.webp",
Файл по этому пути должен существовать. Обычное фото футболки для этого не подходит.

Проверка (необязательно, нужен Node.js):
  node --test tests/wheel.test.cjs

Проверены: новая футболка без принта; заполнение колеса более ранними принтами;
появление товара после добавления принта; исключение худи и удалённых товаров;
пустые/некорректные значения; текущий каталог с Doflamingo.
