Обновление сайта — Футболка Toji Fushiguro

1. Распакуйте архив в корень репозитория сайта, поверх существующих файлов.
   products.js заменится целиком, картинки лягут в images/.

2. Проверьте локально: откройте index.html в браузере.

3. Запушьте:

   git add products.js images/
   git commit -m "Каталог: Футболка Toji Fushiguro"
   git push

GitHub Pages обновит сайт за минуту-две. Если картинки не появились —
проверьте регистр имён файлов: на Pages он важен, на Windows нет.
